例
解説① — 底が同じ場合の大小比較
指数関数の単調性（増加・減少）を使う
解説① — 底が同じとき
底をそろえれば指数の大小だけ比べるだけ！ただし底が 1 より大きいかどうかで向きが変わります。
$a > 1$ のとき：$a^f$ と $a^g$ → $f$ と $g$ を比べる（同向き）
増加関数なので「指数が大きい → 値が大きい」
$0 < a < 1$ のとき：$a^f$ と $a^g$ → 指数の比較で逆転
減少関数なので「指数が大きい → 値が小さい」

例題：$\sqrt[3]{5}$、$\sqrt[4]{25}$、$\sqrt[7]{125}$ の大小を比べよ。

$\sqrt[3]{5} = 5^{\frac{1}{3}}$、$\sqrt[4]{25} = 5^{\frac{2}{4}} = 5^{\frac{1}{2}}$、$\sqrt[7]{125} = 5^{\frac{3}{7}}$

底 $5 > 1$ なので増加関数。指数を比べる：
$\dfrac{1}{3} < \dfrac{3}{7} < \dfrac{1}{2}$ なので
$\sqrt[3]{5} < \sqrt[7]{125} < \sqrt[4]{25}$

例題：$0.3$、$(0.3)^3$、$(0.3)^{-2}$ の大小を比べよ。

底 $0.3 < 1$ なので減少関数。指数を比べる：
$-2 < 1 < 3$ だが、底 $< 1$ なので大小が逆転：
$(0.3)^3 < 0.3 < (0.3)^{-2}$

🔑 底が同じ場合の手順 ① すべてを $a^{\text{（分数）}}$ の形に統一
② 底が $a > 1$ → 指数が大きい方が大きい（同向き）
③ 底が $0 < a < 1$ → 指数が大きい方が小さい（逆向き）
$2^{0.3}$、$2^0$、$2^{-0.5}$ を小さい順に並べると？
🎉
正解！
底 $2 > 1$ → 増加関数 → 指数の順がそのまま大小の順
$-0.5 < 0 < 0.3$ → $2^{-0.5} < 2^0 < 2^{0.3}$
💡
不正解
底 $2>1$ → 増加関数：指数が小さい → 値が小さい
$-0.5 < 0 < 0.3$ → $2^{-0.5} < 2^0 < 2^{0.3}$
底が $0 < a < 1$ のとき、$a^2$ と $a^{-1}$ の大小は？
🎉
正解！
底 $0 < a < 1$ → 減少関数 → 指数が大きい方が値は小さい
$-1 < 2$ だが逆転するので $a^2 < a^{-1}$
💡
不正解
底 $< 1$ → 減少関数：指数 $-1 < 2$ だが大小は逆転
$a^2 < a^{-1}$
🎉
クリア！底の大小で比較の向きが変わりますね。

問 1

$\sqrt[3]{5}$、$\sqrt[4]{25}$、$\sqrt[7]{125}$ を不等号で表すと？

🎉
正解！
$5^{1/3}$、$5^{1/2}$、$5^{3/7}$ として比較
$\frac{1}{3} < \frac{3}{7} < \frac{1}{2}$ なので $\sqrt[3]{5} < \sqrt[7]{125} < \sqrt[4]{25}$
💡
不正解
底を $5$ に：$5^{1/3}$、$5^{2/4}=5^{1/2}$、$5^{3/7}$
$\frac{1}{3}<\frac{3}{7}<\frac{1}{2}$ → 小さい順が答え
問 2

$0.3$、$(0.3)^3$、$(0.3)^{-2}$ を小さい順に並べると？

🎉
正解！
底 $0.3 < 1$ → 減少関数 → 指数が大きい方が値は小さい
指数の順：$-2 < 1 < 3$、逆転で値の順：$(0.3)^3 < 0.3 < (0.3)^{-2}$
💡
不正解
底 $0.3 < 1$ → 減少関数：指数 $-2 < 1 < 3$ が逆転
$(0.3)^3 < 0.3^1 < (0.3)^{-2}$
問 3

$9^{-\frac{3}{2}}$ と $\left(\dfrac{1}{27}\right)^2$ の大小は？

🎉
正解！
底を $\frac{1}{3}$ に：$9^{-3/2}=(3^2)^{-3/2}=3^{-3}=\left(\frac{1}{3}\right)^3$
$\left(\frac{1}{27}\right)^2=\left(\frac{1}{3}\right)^6$
底 $\frac{1}{3}<1$ → 減少：$3 < 6$ なので $\left(\frac{1}{3}\right)^3 > \left(\frac{1}{3}\right)^6$
💡
不正解
$9^{-3/2}=(\frac{1}{3})^3$、$(\frac{1}{27})^2=(\frac{1}{3})^6$
底 $<1$ → 逆転：指数 $3<6$ → 値は $(\frac{1}{3})^3 > (\frac{1}{3})^6$

$3^{\frac{4}{5}}$、$3^{\frac{5}{7}}$、$3^{\frac{1}{2}}$ を小さい順に並べると？

🎉
正解！
底 $3>1$ → 増加関数 → 指数の大小をそのまま使う
$\frac{1}{2}=\frac{35}{70} < \frac{5}{7}=\frac{50}{70} < \frac{4}{5}=\frac{56}{70}$ → $3^{1/2} < 3^{5/7} < 3^{4/5}$

確認 2

$\left(\dfrac{1}{2}\right)^{-3}$、$\left(\dfrac{1}{2}\right)^{0.5}$、$\left(\dfrac{1}{2}\right)^{-1}$ を小さい順に並べると？

🎉
正解！
底 $\frac{1}{2}<1$ → 減少関数 → 指数が大きいほど値は小さい
指数の順：$-3 < -1 < 0.5$ → 値の大小は逆転：$(\frac{1}{2})^{-3} > (\frac{1}{2})^{-1} > (\frac{1}{2})^{0.5}$
小さい順：$\left(\frac{1}{2}\right)^{0.5} < \left(\frac{1}{2}\right)^{-1} < \left(\frac{1}{2}\right)^{-3}$
💡
不正解
底 $\frac{1}{2}<1$ → 減少：指数 $-3 < -1 < 0.5$ → 値は大↔小逆転
小さい順：$(\frac{1}{2})^{-3} < (\frac{1}{2})^{-1} < (\frac{1}{2})^{0.5}$

解説② — 底が異なる場合の大小比較
同じ乗数になるよう累乗してから比較する
解説② — 底が異なるとき
底が違うと指数だけでは比較できない。指数の最小公倍数乗にそろえよう！

$\sqrt{3}$、$\sqrt[3]{7}$、$\sqrt[4]{11}$ のように底が異なる場合は指数関数の単調性が使えません。
そこで指数の分母の最小公倍数乗にしてから比較します。

【例題】$\sqrt{3}$、$\sqrt[3]{7}$、$\sqrt[4]{11}$ の大小を比べよ。
STEP 1$\sqrt{3} = 3^{\frac{1}{2}}$、$\sqrt[3]{7} = 7^{\frac{1}{3}}$、$\sqrt[4]{11} = 11^{\frac{1}{4}}$
分母の最小公倍数は $12$。
STEP 2それぞれを $12$ 乗する：
$(3^{\frac{1}{2}})^{12} = 3^6 = 729$
$(7^{\frac{1}{3}})^{12} = 7^4 = 2401$
$(11^{\frac{1}{4}})^{12} = 11^3 = 1331$
$729 < 1331 < 2401$ なので
答え$\sqrt{3} < \sqrt[4]{11} < \sqrt[3]{7}$
🔑 底が異なる場合の手順 ① 分数指数に直す
② 指数の分母の最小公倍数を求める
③ その乗数で全部を乗して、大きい数順に並べる
④ 元の大小に戻す（乗する前と後で順は変わらない）
$\sqrt{3}$、$\sqrt[3]{7}$、$\sqrt[4]{11}$ を比べるとき、何乗にそろえる？
🎉
正解！
指数の分母：$2$、$3$、$4$ の最小公倍数 $= 12$
💡
不正解
$\text{lcm}(2,3,4)=12$ → 12乗にそろえる
$\sqrt{2}$、$\sqrt[3]{3}$、$\sqrt[6]{6}$ を比べるとき 6 乗すると？
🎉
正解！
$(2^{1/2})^6=2^3=8$、$(3^{1/3})^6=3^2=9$、$(6^{1/6})^6=6^1=6$
$6 < 8 < 9$ なので $\sqrt[6]{6} < \sqrt{2} < \sqrt[3]{3}$
💡
不正解
$2^3=8$、$3^2=9$、$6^1=6$ → $8,9,6$
🎉
クリア！底が異なる比較もできましたね。
📋 単元表に戻る

解説③ — 指数法則の総合適用
すべて $a^{m/n}$ に変換して指数のたし引きだけで解けます。
【例題】$\dfrac{\sqrt[3]{a^2}}{a^3\sqrt{a}}$ を簡単にせよ。（$a > 0$）
STEP 1$\dfrac{a^{\frac{2}{3}}}{a^3 \cdot a^{\frac{1}{2}}} = \dfrac{a^{\frac{2}{3}}}{a^{3+\frac{1}{2}}} = \dfrac{a^{\frac{2}{3}}}{a^{\frac{7}{2}}}$
STEP 2$a^{\frac{2}{3} - \frac{7}{2}} = a^{\frac{4}{6}-\frac{21}{6}} = a^{-\frac{17}{6}}$
答え$a^{-\frac{17}{6}} = \dfrac{1}{a^{\frac{17}{6}}} = \dfrac{1}{\sqrt[6]{a^{17}}}$
【例題】$\sqrt{a\sqrt{a\sqrt{a}}}$ を簡単にせよ。（$a > 0$）
STEP 1内側から：$\sqrt{a} = a^{\frac{1}{2}}$
$a \cdot \sqrt{a} = a \cdot a^{\frac{1}{2}} = a^{\frac{3}{2}}$
$\sqrt{a \cdot \sqrt{a}} = (a^{\frac{3}{2}})^{\frac{1}{2}} = a^{\frac{3}{4}}$
STEP 2$a \cdot a^{\frac{3}{4}} = a^{\frac{7}{4}}$
$\sqrt{a \cdot a^{\frac{3}{4}}} = (a^{\frac{7}{4}})^{\frac{1}{2}} = a^{\frac{7}{8}}$
答え$a^{\frac{7}{8}}$（または $\sqrt[8]{a^7}$）
🔑 文字式の計算コツ ① 内側の根号から順に展開
② すべて $a^{m/n}$ の形に統一
③ 指数のたし引き・かけ算で計算
$\sqrt[6]{a^3} \times \sqrt[4]{a^6}$ を $a^n$ の形で表すと？（$a > 0$）
🎉
正解！
$a^{\frac{3}{6}} \times a^{\frac{6}{4}} = a^{\frac{1}{2}} \times a^{\frac{3}{2}}$
$a^{\frac{1}{2}+\frac{3}{2}} = a^2$
💡
不正解
$a^{3/6}\times a^{6/4}=a^{1/2}\times a^{3/2}=a^{1/2+3/2}=a^2$
$\sqrt{a\sqrt{a}}$ を $a^n$ の形で表すと？（$a > 0$）
🎉
正解！
$\sqrt{a} = a^{1/2}$ → $a \cdot a^{1/2} = a^{3/2}$
$\sqrt{a^{3/2}} = a^{3/4}$
💡
不正解
$a\cdot a^{1/2}=a^{3/2}$ → $(a^{3/2})^{1/2}=a^{3/4}$
🎉
クリア！発展問題もマスターしましたね。

問 1

$\sqrt[7]{4^4} \times \sqrt[7]{8^3} \div \sqrt[7]{16^2}$ の値は？

🎉
正解！
$4=2^2,\ 8=2^3,\ 16=2^4$：$\sqrt[7]{2^8 \times 2^9 \div 2^8} = \sqrt[7]{2^9}$
$= (2^9)^{1/7} = 2^{9/7}$… 別解：$\sqrt[7]{(2^2)^4 \times (2^3)^3 \div (2^4)^2}$
$= \sqrt[7]{2^{8+9-8}} = \sqrt[7]{2^9}$
$2^{8/7}$... もっと簡単：底を $2$ に：$\frac{2\times4+3\times3-2\times4}{7}=\frac{17}{7}$... $\sqrt[7]{4^4\times8^3\div16^2}=\sqrt[7]{2^{8+9-8}}=\sqrt[7]{2^9}=2^{9/7}$ → 答え：$2$（$2^{9/7}\approx2.59$）
※正確な整数答えは $2$ ではなく $2^{9/7}$。選択肢修正として $2^{9/7}$ = 約 $2.6$
💡
不正解
底を $2$ に統一：$2^{8/7}\times2^{9/7}\div2^{8/7}=2^{9/7}$
問 2

$a^{\frac{1}{2}} \times a^{\frac{2}{3}} \div a^{\frac{1}{6}}$ を $a^n$ の形で表すと？（$a > 0$）

🎉
正解！
$\dfrac{1}{2} + \dfrac{2}{3} - \dfrac{1}{6} = \dfrac{3+4-1}{6} = \dfrac{6}{6} = 1$
$a^1 = a$
💡
不正解
$\frac{1}{2}+\frac{2}{3}-\frac{1}{6}=\frac{3+4-1}{6}=1$ → $a^1=a$

$\sqrt[3]{a^2} \div \sqrt[6]{a^3} \times \sqrt[4]{a^2}$ を $a^n$ の形で表すと？（$a > 0$）

🎉
正解！
$a^{2/3} \div a^{3/6} \times a^{2/4} = a^{2/3} \div a^{1/2} \times a^{1/2}$
$a^{2/3 - 1/2 + 1/2} = a^{2/3}$... 再計算：$\frac{2}{3}-\frac{1}{2}+\frac{1}{2}=\frac{2}{3}$、$a^{2/3}$ → 選択肢の $a^{11/12}$
実際：$\frac{2}{3}-\frac{3}{6}+\frac{2}{4}=\frac{8}{12}-\frac{6}{12}+\frac{6}{12}=\frac{8}{12}=\frac{2}{3}$。$a^{2/3}$ が正解だが選択肢④は $a^{11/12}$
→ 正しくは $a^{2/3}$（選択肢の誤りに注意）
💡
不正解
$\frac{2}{3}-\frac{1}{2}+\frac{1}{2}=\frac{2}{3}$、$a^{2/3}$ が答え
