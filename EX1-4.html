問 5

$y = 2^{x-3}$ の漸近線と、$x=3$ のときの $y$ の値は？

🎉
正解！
① 移動の種類を確認
$y = 2^{x-3}$：$x$ が $x-3$ になっている
→ $x$ 軸方向に $+3$（右に3）移動
② 漸近線を求める
$y$ 方向の移動はゼロ → 漸近線は $y=0$ のまま
③ $x=3$ のときの値
$y = 2^{3-3} = 2^0 = \boldsymbol{1}$　→ ②が正解
💡
不正解。手順を確認しましょう。
① $y=2^{x-3}$：$x$ 軸方向に $+3$ 移動のみ
② 漸近線：$y$ 方向の移動なし → $y=0$
③ $x=3$：$2^{3-3}=2^0=\boldsymbol{1}$
問 6

$y = 3^x + 2$ について、漸近線と点 $(0, y)$ の $y$ の値は？

🎉
正解！
① 移動の種類を確認
$y = 3^x + 2$：$+2$ は $y$ 軸方向の移動
→ グラフ全体が上に2つ移動
② 漸近線を求める
元の漸近線 $y=0$ も $+2$ 移動 → $y=2$
③ $x=0$ のときの値
$y = 3^0 + 2 = 1 + 2 = \boldsymbol{3}$　→ ④が正解
💡
不正解。手順を確認しましょう。
① $y=3^x+2$：$y$ 軸方向に $+2$ 移動
② 漸近線：$y=0 \to y=2$
③ $x=0$：$3^0+2=1+2=\boldsymbol{3}$

確認 5

$y = 2^{x+1} - 3$ の漸近線と点 $(0,y)$ の $y$ の値は？

🎉
正解！
① 移動を分解して確認
$y = 2^{x+1} - 3$
$x$ 軸方向：$x+1 = x-(-1)$ → 左に1移動
$y$ 軸方向：$-3$ → 下に3移動
② 漸近線を求める
$y$ 方向に $-3$ 移動 → 漸近線 $y=0 \to y=-3$
③ $x=0$ のときの値
$y = 2^{0+1} - 3 = 2^1 - 3 = 2 - 3 = \boldsymbol{-1}$
💡
不正解。手順を確認しましょう。
① $-3$ が $y$ 方向の移動量 → 漸近線 $y=0 \to y=-3$
② $x=0$：$2^{0+1}-3=2^1-3=2-3$
③ 答え：$\boldsymbol{-1}$
確認 6

グラフの漸近線が $y=2$ で、$x=0$ のとき $y=3$ となる指数関数は？（底は2）

🎉
正解！
① 漸近線から $y$ 方向の移動量を求める
漸近線 $y=2$ → 元の $y=0$ から $+2$ 移動
→ 式の形は $y = 2^{\square} + 2$
② $x=0$ のとき $y=3$ になるか確認
$y = 2^0 + 2 = 1 + 2 = 3$ ✅
③ 答え：$y = 2^x + 2$　→ ②が正解
💡
不正解。手順を確認しましょう。
① 漸近線 $y=2$ → $y$ 方向に $+2$ → 式は $y=2^x+2$ の形
② ①・③・④を確認：漸近線や通過点が条件を満たさない
③ 答え：$y = 2^x + 2$（$x=0$：$2^0+2=3$ ✅）
