解説① — 指数不等式の基本：底と不等号の向き
$a>1$ なら同向き、$0<a<1$ なら逆向き
解説① — 指数不等式〔1〕
方程式とほぼ同じ！ただし「底が $1$ より小さいと不等号が逆転」するのが最大のポイント。

指数不等式も「底をそろえる」のが基本です。
そろえたあとの不等号の向きは底の大きさによって変わります。

$a > 1$ のとき：$a^f \geqq a^g \Longrightarrow f \geqq g$（同じ向き）
$0 < a < 1$ のとき：$a^f \geqq a^g \Longrightarrow f \leqq g$（逆向き）
指数関数が増加か減少かによって、不等号の向きが決まる
📈 $a > 1$（増加関数）
$x$ が大きい → $a^x$ も大きい
不等号の向き：そのまま
例：$2^x > 2^3 \Rightarrow x > 3$
📉 $0 < a < 1$（減少関数）
$x$ が大きい → $a^x$ は小さい
不等号の向き：逆転！
例：$\left(\frac{1}{2}\right)^x > \left(\frac{1}{2}\right)^3 \Rightarrow x < 3$

なぜ逆転するの？イメージで理解

$y = \left(\frac{1}{2}\right)^x$ は $x$ が増えると $y$ が減るグラフ（右下がり）。
だから「$y$ が大きい」→「$x$ が小さい」という逆の関係になる。
底を見て「$1$ より大きいか小さいか」を確認する習慣をつけよう！

【例題①】$5^x \geqq 125$ を解け。
STEP 1 $125 = 5^3$ と変形：
$5^x \geqq 5^3$
STEP 2 底 $5 > 1$ なので、$5^x$ は増加関数
→ 不等号の向きそのまま：
$x \geqq 3$
答え $x \geqq 3$
【例題②】$\left(\dfrac{1}{2}\right)^{2x+1} < 8$ を解け。
STEP 1 $8 = 2^3 = \left(\dfrac{1}{2}\right)^{-3}$ と変形：
$\left(\dfrac{1}{2}\right)^{2x+1} < \left(\dfrac{1}{2}\right)^{-3}$
STEP 2 底 $\dfrac{1}{2} < 1$ なので、$\left(\dfrac{1}{2}\right)^x$ は減少関数
→ 不等号の向き逆転：
$2x + 1 > -3$
STEP 3 $2x > -4$
$x > -2$
答え $x > -2$
🔑 解法の手順まとめ ① 両辺を同じ底のべき乗に変形する
② 底を確認：$a > 1$ なら不等号そのまま、$0 < a < 1$ なら不等号逆転

練習問題③ — 発展パターンの練習
3次型・$(t-c)^2$ 型の不等式を解く
0 / 2 完了
問 1

$2^{2x} - 5 \cdot 2^x + 4 \leqq 0$ から $0 \leqq x \leqq 2$ が導けます。
では、$2^{2x} - 5 \cdot 2^{x-1} + 1 < 0$ の解は？

🎉
正解！
$2^{x-1} = \frac{t}{2}$（$t = 2^x$）なので $t^2 - \frac{5}{2}t + 1 < 0$
$2t^2 - 5t + 2 < 0$、$(2t-1)(t-2) < 0$、$\frac{1}{2} < t < 2$
$2^{-1} < 2^x < 2^1$、底 $2>1$ → $-1 < x < 1$
💡
不正解
$5 \cdot 2^{x-1} = \frac{5}{2} \cdot 2^x = \frac{5t}{2}$ に注意！
$2t^2 - 5t + 2 < 0 \Rightarrow (2t-1)(t-2) < 0 \Rightarrow \frac{1}{2} < t < 2$
$-1 < x < 1$
問 2

$8^x - 5 \cdot 4^x + 2^{x+3} - 4 < 0$ を解け。
（$(t-2)^2(t-1) < 0$ の形を使う）

🎉
正解！
$2^x = t$ → $t^3 - 5t^2 + 8t - 4 < 0$
$(t-2)^2(t-1) < 0$
$(t-2)^2 \geqq 0$ なので $(t-1) < 0$ かつ $t \neq 2$
$0 < t < 1$（$t > 0$ も考慮）
$0 < 2^x < 1 = 2^0$、底 $2>1$ → $x < 0$
💡
不正解
$(t-2)^2(t-1) < 0$ で $(t-2)^2 \geqq 0$ より $(t-1) < 0$ が必要
$t < 1$、$t > 0$ より $0 < t < 1$
$2^x < 2^0 \Rightarrow x < 0$

確認問題③ — 総合問題
指数不等式の全パターンを総合的に確認
0 / 2 完了
確認 1

$\left(\dfrac{1}{3}\right)^{2x+1} \leqq \dfrac{1}{3}$ を解け。

🎉
正解！
$\dfrac{1}{3} = \left(\dfrac{1}{3}\right)^1$ と変形：$\left(\dfrac{1}{3}\right)^{2x+1} \leqq \left(\dfrac{1}{3}\right)^1$
底 $\dfrac{1}{3} < 1$ → 不等号逆転：$2x+1 \geqq 1$
$2x \geqq 0$、$x \geqq 0$
💡
不正解
底 $\frac{1}{3} < 1$ → 減少関数 → 不等号逆転
$2x+1 \geqq 1 \Rightarrow x \geqq 0$
確認 2

$2^{2x} - 5 \cdot 2^x + 4 < 0$ を解け。

🎉
正解！
$2^x = t$（$t>0$）：$t^2 - 5t + 4 < 0$
$(t-1)(t-4) < 0$、$1 < t < 4$
$2^0 < 2^x < 2^2$、底 $2>1$ → $0 < x < 2$
💡
不正解
$t^2 - 5t + 4 = (t-1)(t-4) < 0 \Rightarrow 1 < t < 4$
$2^x$ に戻す：$1 < 2^x < 4 \Rightarrow 0 < x < 2$
