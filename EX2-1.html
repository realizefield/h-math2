① 対数とは何か

指数関数 $y = a^x$ のグラフを思い出しましょう。

$a > 1$ のとき（増加）
$0 < a < 1$ のとき（減少）
📐 なぜ log という記号が必要になったのか？
STEP 1   逆関数とは（一次関数で確認）

$y = 2x$ の対応を見てみましょう。

$x$$1$$2$$3$
$y$$2$$4$$6$

逆に $y=2$ を入れると $x=1$，$y=4$ を入れると $x=2$ …

この逆の対応を表す関数を 逆関数 といいます。

① $y = 2x$

② $x$ と $y$ を入れ替えると $x = 2y$

③ $y$ について解くと  $y = \frac{1}{2}x$  これが逆関数

$y=2x$ と $y=\frac{1}{2}x$ は直線 $y=x$ に関して対称です。

STEP 2   $y = x^2$ でも確認

$y = x^2$ の対応を見てみましょう。

$x$$1$$2$$3$
$y$$1$$4$$9$

逆に $y=1$ を入れると $x=1$，$y=4$ を入れると $x=2$ …

① $y = x^2$

② $x$ と $y$ を入れ替えると $x = y^2$

③ $y$ について解くと（$y \geqq 0$） $y = \sqrt{x}$  これが逆関数

$y=x^2$ と $y=\sqrt{x}$ は直線 $y=x$ に関して対称です。

STEP 3   $y = a^x$ の逆関数 → log の誕生！

$y = a^x$ の対応を見てみましょう。

$x$$1$$2$$3$
$y$$a^1$$a^2$$a^3$

① $y = a^x$

② $x$ と $y$ を入れ替えると $x = a^y$

③ $y$ について解こうとすると…

❗ 今までの方法では $y =$ の形に解けない！

そこで 「$a$ を何乗すれば $x$ になるか」 を表す新しい記号を作ることにしました。

$$x = a^y \quad \Longrightarrow \quad y = \log_a x$$

$y=a^x$ と $y=\log_a x$ は $(x,\,y)$ の点について，直線 $y=x$ に関して対称です。

📌 対数の定義

$a > 0,\ a \neq 1,\ b > 0$ のとき，

$$a^P = b \iff P = \log_a b$$

この $P$ を「$a$ を底とする $b$ の対数」といいます。

$b$ を真数といい，$b > 0$ でなければなりません。

【重要】変換の向き
$$a^P = b \quad\Longleftrightarrow\quad P = \log_a b$$

「指数の式」と「対数の式」は互いに変換できます

例題 指数の式 → 対数の式
例題1

$3^{-2} = \dfrac{1}{9}$ を，対数を用いて表せ。

底 $a = 3$，真数 $b = \dfrac{1}{9}$，指数 $P = -2$ と対応させます。

$a^P = b$ の形から $P = \log_a b$ に変換すると，

$$-2 = \log_3 \frac{1}{9}$$

答え：$-2 = \log_3 \dfrac{1}{9}$

例題2

$\dfrac{1}{2} = \log_5 \sqrt{5}$ を，指数を用いて表せ。

底 $a = 5$，$P = \dfrac{1}{2}$，真数 $b = \sqrt{5}$ と読み取ります。

$P = \log_a b$ の形から $a^P = b$ に変換すると，

$$5^{\frac{1}{2}} = \sqrt{5}$$

答え：$5^{\frac{1}{2}} = \sqrt{5}$

ミニテスト
$2^4 = 16$ を対数で表すと？
$5^{-3} = \dfrac{1}{125}$ を対数で表すと？
練習① 指数↔対数の変換

次の式を，対数（または指数）を用いて表しなさい。

問1

$2^4 = 16$ を対数で表せ。

解答

底 $a=2$，指数 $P=4$，真数 $b=16$ なので，

$$4 = \log_2 16$$
問2

$5^{-3} = \dfrac{1}{125}$ を対数で表せ。

解答

底 $a=5$，指数 $P=-3$，真数 $b=\dfrac{1}{125}$ なので，

$$-3 = \log_5 \frac{1}{125}$$
問3

$\left(\dfrac{1}{2}\right)^3 = \dfrac{1}{8}$ を対数で表せ。

解答

底 $a=\dfrac{1}{2}$，指数 $P=3$，真数 $b=\dfrac{1}{8}$ なので，

$$3 = \log_{\frac{1}{2}} \frac{1}{8}$$
問4

$4 = \log_3 81$ を指数で表せ。

解答

$P = \log_a b \Rightarrow a^P = b$ に対応させると，

$$3^4 = 81$$
問5

$-2 = \log_5 \dfrac{1}{25}$ を指数で表せ。

解答
$$5^{-2} = \frac{1}{25}$$
確認① 変換の確認テスト
確認1

次の式を対数を使って表せ。

(1) $3^5 = 243$    (2) $\left(\dfrac{1}{4}\right)^{-2} = 16$

解答

(1) $5 = \log_3 243$

(2) $-2 = \log_{\frac{1}{4}} 16$

確認2

次の式を指数を使って表せ。

(1) $\dfrac{1}{3} = \log_{1000} 10$    (2) $\dfrac{1}{2} = \log_9 3$

解答

(1) $1000^{\frac{1}{3}} = 10$

(2) $9^{\frac{1}{2}} = 3$

② 対数の値を求める
📌 対数の値の求め方

$\log_a b = x$ とおいて，$a^x = b$ に変換し，$x$ の値を求めます。

例題3

$\log_2 8$ の値を求めよ。

$\log_2 8 = x$ とおきます。

対数の定義より $2^x = 8$ に変換します。

$8 = 2^3$ なので，$2^x = 2^3$

底が同じなので指数を比較して，$x = 3$

答え：$\log_2 8 = 3$

例題4

$\log_3 9\sqrt{3}$ の値を求めよ。

$\log_3 9\sqrt{3} = x$ とおくと，$3^x = 9\sqrt{3}$

$9\sqrt{3} = 3^2 \times 3^{\frac{1}{2}} = 3^{2+\frac{1}{2}} = 3^{\frac{5}{2}}$

よって $3^x = 3^{\frac{5}{2}}$ より $x = \dfrac{5}{2}$

答え：$\log_3 9\sqrt{3} = \dfrac{5}{2}$

ミニテスト
$\log_7 49$ の値は？
$\log_{10} 1000$ の値は？
練習② 対数の値を求める
問1

$\log_2 \sqrt{8}$ の値を求めよ。

解答

$\log_2 \sqrt{8} = x$ とおくと，$2^x = \sqrt{8} = (2^3)^{\frac{1}{2}} = 2^{\frac{3}{2}}$

よって $x = \dfrac{3}{2}$

問2

$\log_6 \dfrac{1}{36}$ の値を求めよ。

解答

$6^x = \dfrac{1}{36} = 6^{-2}$ より $x = -2$

問3

$\log_{0.5} \dfrac{1}{4}$ の値を求めよ。

解答

$(0.5)^x = \dfrac{1}{4}$ → $\left(\dfrac{1}{2}\right)^x = \left(\dfrac{1}{2}\right)^2$ より $x = 2$

問4

$\log_5 \dfrac{\sqrt{5}}{25}$ の値を求めよ。

解答

$\dfrac{\sqrt{5}}{25} = \dfrac{5^{\frac{1}{2}}}{5^2} = 5^{\frac{1}{2}-2} = 5^{-\frac{3}{2}}$

よって $x = -\dfrac{3}{2}$

確認② 対数の値
確認1

次の対数の値を求めよ。

(1) $\log_3 \sqrt{27}$    (2) $\log_{0.25} 5$

解答

(1) $\sqrt{27} = 3^{\frac{3}{2}}$ なので $\log_3 \sqrt{27} = \dfrac{3}{2}$

(2) $0.25 = \dfrac{1}{4} = \left(\dfrac{1}{5}\right)^{\,?}$…$\left(\dfrac{1}{5}\right)^x = \dfrac{1}{5}$ より $x=-1$

確認2

$\log_{0.5} \dfrac{1}{4}$ と $\log_3 9\sqrt{3}$ の値をそれぞれ求めよ。

解答

$\log_{0.5} \dfrac{1}{4} = 2$

$\log_3 9\sqrt{3} = \dfrac{5}{2}$

③ 底 $x$ を求める問題・対数の基本性質
⚠️ 底の条件

$\log_x b = P$ において，底 $x$ は $x > 0,\ x \neq 1$ でなければなりません。

例題5（関西大工学部）

$\log_x 81 = 4$ を満たす $x$ を求めよ。

$x^4 = 81$ に変換します。

底は正の数なので $x > 0$

$x^4 = 3^4$ より $x = 3$

答え：$x = 3$

対数の基本性質①
【重要】覚えておくべき2つの性質

$\log_a a = 1$  （$a^1 = a$ だから）

$\log_a 1 = 0$  （$a^0 = 1$ だから）

確認

$\log_5 5 = ?$    $\log_3 1 = ?$

$\log_5 5 = 1$（なぜなら $5^1 = 5$）

$\log_3 1 = 0$（なぜなら $3^0 = 1$）

ミニテスト
$\log_x \sqrt{8} = 3$ を満たす $x$ は？
$\log_7 1$ の値は？
練習③ 底を求める・基本性質
問1

$\log_x \sqrt{8} = 3$ を満たす $x$ を求めよ。

解答

$x^3 = \sqrt{8} = (2^3)^{\frac{1}{2}} = 2^{\frac{3}{2}} = (2^{\frac{1}{2}})^3$

よって $x = 2^{\frac{1}{2}} = \sqrt{2}$

問2

$\log_x 3 = 2$ を満たす $x$ を求めよ。

解答

$x^2 = 3$ より，$x > 0$ なので $x = \sqrt{3}$

問3

次の値を求めよ。(1) $\log_4 4$    (2) $\log_{10} 1$    (3) $\log_2 1$

解答

(1) $\log_4 4 = 1$

(2) $\log_{10} 1 = 0$

(3) $\log_2 1 = 0$

確認③ 総合確認
確認1

次の $x$ の値を求めよ。

(1) $\log_x 81 = 4$    (2) $\log_x 3 = 2$

解答

(1) $x^4 = 81 = 3^4$ より $x = 3$

(2) $x^2 = 3$ より $x = \sqrt{3}$

確認2

次の値を求めよ。

(1) $\log_2 32$    (2) $\log_3 \dfrac{1}{27}$    (3) $\log_5 5$

解答

(1) $32 = 2^5$ なので $\log_2 32 = 5$

(2) $\dfrac{1}{27} = 3^{-3}$ なので $\log_3 \dfrac{1}{27} = -3$

(3) $\log_5 5 = 1$
