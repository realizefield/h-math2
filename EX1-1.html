解説① — 指数法則（たす・かける・ひく）
$a^m \times a^n = a^{m+n}$ など3つの法則をマスターする
解説① — 指数法則の3公式
まずは「指数」の意味を確認してから、3つの法則を学びましょう。

そもそも「指数」とは？

$2^3$（2の3乗）とは、2を3回かけ合わせた数のことです。

$2^3 = \underbrace{2 \times 2 \times 2}_{3\text{個}} = 8$

このとき、$2$ を底（てい）、$3$ を指数（しすう）といいます。
$5^4 = 5 \times 5 \times 5 \times 5 = 625$ のように、底と指数を変えるといろいろな数になります。

① 掛け算のとき — 指数をたす

なぜ指数をたすの？

$2^3 \times 2^2$ を計算してみましょう。

$2^3 = \underbrace{2\times2\times2}_{3\text{個}}$　，　$2^2 = \underbrace{2\times2}_{2\text{個}}$

続けてかけると：$\underbrace{2\times2\times2}_{3\text{個}} \times \underbrace{2\times2}_{2\text{個}} = \underbrace{2\times2\times2\times2\times2}_{3+2=5\text{個}} = 2^5$

つまり、底が同じ掛け算は指数をたすだけでOKです。

$a^m \times a^n = a^{m+n}$
底が同じ掛け算 → 指数をたす　（底が違う場合は使えません！）

例で確認

$3^4 \times 3^5 = 3^{4+5} = 3^9$　← 底が同じ（3）なので指数をたす
$2^6 \times 2^3 = 2^{6+3} = 2^9$
$a^2 \times a^7 = a^{2+7} = a^9$（文字でも同じ！）

② べき乗のべき乗 — 指数をかける

$(a^m)^n$ とは？

$(2^3)^4$ は「$2^3$ を 4回かけ合わせる」という意味です。

$(2^3)^4 = \underbrace{2^3 \times 2^3 \times 2^3 \times 2^3}_{4\text{個}}$

法則①を使うと：$= 2^{3+3+3+3} = 2^{3\times4} = 2^{12}$

つまり、指数どうしをかけるだけでOKです。

$(a^m)^n = a^{m \times n}$
べき乗のべき乗 → 指数をかける

例で確認

$(5^2)^3 = 5^{2\times3} = 5^6$
$(3^4)^2 = 3^{4\times2} = 3^8$
$\{(2^3)^2\}^4$：
　まず内側：$(2^3)^2 = 2^{3\times2} = 2^6$
　次に外側：$(2^6)^4 = 2^{6\times4} = 2^{24}$
　（または $2^{3\times2\times4} = 2^{24}$ と一気に計算してもOK）

③ 割り算のとき — 指数をひく

なぜ指数をひくの？

$2^5 \div 2^3$ を計算してみましょう。

$\dfrac{2^5}{2^3} = \dfrac{2\times2\times2\times2\times2}{2\times2\times2} = \dfrac{\cancel{2}\times\cancel{2}\times\cancel{2}\times2\times2}{\cancel{2}\times\cancel{2}\times\cancel{2}} = 2\times2 = 2^2$

分子・分母で約分すると、指数の差だけ残ります。
$2^5 \div 2^3 = 2^{5-3} = 2^2$　← 指数をひく

$a^m \div a^n = a^{m-n}$
底が同じ割り算 → 指数をひく　（$a \neq 0$）

例で確認

$7^5 \div 7^2 = 7^{5-2} = 7^3$
$a^9 \div a^3 = a^{9-3} = a^6$
$2^8 \times 2^{11} \div 2^8 = 2^{8+11-8} = 2^{11}$　← 掛け算・割り算は同時にできる！

⚠️ よくあるまちがい $2^3 \times 3^2$ → 底が違う（2と3）ので指数はたせません！
$2^3 \times 2^2 = 2^6$ は間違い（$2^3 \times 2^2 = 2^{3+2} = 2^5$ が正しい）
🔑 3つの法則まとめ ① $a^m \times a^n = a^{m+n}$　（底が同じ掛け算 → 指数をたす）
② $(a^m)^n = a^{m \times n}$　（べき乗のべき乗 → 指数をかける）
③ $a^m \div a^n = a^{m-n}$　（底が同じ割り算 → 指数をひく）

※ 底が違うときはこれらの法則は使えません。
$2^3 \times 2^6$ を計算すると？
🎉
正解！
$3+6=9$ → $2^9$
💡
不正解
底が同じ掛け算：指数をたす $3+6=9$
$(2^4)^2$ を計算すると？
🎉
正解！
べき乗のべき乗：$4\times2=8$ → $2^8$
💡
不正解
$(a^m)^n=a^{mn}$：$4\times2=8$
🎉
指数法則、バッチリ！

解説② — $a^0 = 1$、$a^{-1} = \dfrac{1}{a}$ とは？
指数法則を $0$ や負の数に拡張します。「マイナス乗は逆数」がキーワードです。

$a^0 = 1$ の導き方

法則③ $a^m \div a^n = a^{m-n}$ で $m = n$ とすると：

$a^3 \div a^3 = \dfrac{a^3}{a^3} = 1$　← 同じ数を割ると $1$

一方、法則③を使うと：$a^3 \div a^3 = a^{3-3} = a^0$

両方とも $a^3 \div a^3$ なので、$\boldsymbol{a^0 = 1}$（$a \neq 0$）

$a^0 = 1$　（$a \neq 0$、どんな数の $0$ 乗も $1$）
例：$5^0=1$、$100^0=1$、$(-3)^0=1$、$0.5^0=1$

$a^{-1} = \dfrac{1}{a}$ の導き方

$a^1 \div a^2 = \dfrac{a}{a^2} = \dfrac{1}{a}$　← 約分すると $\dfrac{1}{a}$

法則③を使うと：$a^1 \div a^2 = a^{1-2} = a^{-1}$

よって $\boldsymbol{a^{-1} = \dfrac{1}{a}}$（逆数）

$a^{-m} = \dfrac{1}{a^m}$ への拡張

同じ考え方で：$a^{-2} = \dfrac{1}{a^2}$、$a^{-3} = \dfrac{1}{a^3}$、…

一般に $\boldsymbol{a^{-m} = \dfrac{1}{a^m}}$

分数の場合：$\left(\dfrac{a}{b}\right)^{-m} = \left(\dfrac{b}{a}\right)^m$（ひっくり返してプラス乗）

例：$\left(\dfrac{2}{3}\right)^{-2} = \left(\dfrac{3}{2}\right)^2 = \dfrac{9}{4}$

⚠️ よくある間違い $2^{-3} = -8$ は間違い！マイナスは符号ではなく「逆数」です。
正しくは $2^{-3} = \dfrac{1}{2^3} = \dfrac{1}{8}$
🔑 まとめ $a^0 = 1$（0乗は必ず $1$）
$a^{-1} = \dfrac{1}{a}$（マイナス1乗は逆数）
$a^{-m} = \dfrac{1}{a^m}$（マイナス乗は分母に移す）
$\left(\dfrac{a}{b}\right)^{-m} = \left(\dfrac{b}{a}\right)^m$（分数はひっくり返す）
$7^0$ の値は？
🎉
正解！
$a^0=1$：$7^0=1$
💡
不正解
どんな数の0乗も1
$3^{-1}$ の値は？
🎉
正解！
$a^{-1}=\dfrac{1}{a}$：$3^{-1}=\dfrac{1}{3}$
💡
不正解
マイナス1乗は逆数
🎉
0乗・負の指数、マスター！

解説③ — 分数指数・累乗根・総合計算
すべて $a^{m/n}$ の形に直してから計算するのが最も確実！

分数指数 $a^{1/n}$ とは？

$(a^{1/2})^2 = a^{1/2 \times 2} = a^1 = a$ なので、
$a^{1/2}$ は「2乗すると $a$ になる数」＝ $\sqrt{a}$（平方根）です。

同様に $a^{1/3}$ は「3乗すると $a$ になる数」＝ $\sqrt[3]{a}$（3乗根）

一般に：$a^{1/n} = \sqrt[n]{a}$（$n$ 乗根）

$a^{\frac{m}{n}} = \sqrt[n]{a^m} = (\sqrt[n]{a})^m$
分母が根号の次数、分子が乗数

計算の手順：すべて $a^{m/n}$ に変換する

$\sqrt[3]{4} = 4^{1/3}$、$\sqrt{8} = 8^{1/2} = (2^3)^{1/2} = 2^{3/2}$

$9^{1/4} \times \sqrt[3]{9} \div 9^{1/12}$
$= 9^{1/4} \times 9^{1/3} \div 9^{1/12}$
$= 9^{1/4 + 1/3 - 1/12}$　← 指数をたし引き
$= 9^{3/12 + 4/12 - 1/12} = 9^{6/12} = 9^{1/2} = 3$

底が違う場合：まず底をそろえる

$25^{1.5} \times 32^{-0.2}$
$25 = 5^2$、$32 = 2^5$ に変換：
$(5^2)^{1.5} \times (2^5)^{-0.2}$
$= 5^{2 \times 1.5} \times 2^{5 \times (-0.2)}$
$= 5^3 \times 2^{-1}$
$= 125 \times \dfrac{1}{2} = \dfrac{125}{2}$

🔑 総合計算の手順 ① 底を同じにそろえる（素因数分解を活用）
② $\sqrt[n]{a} = a^{1/n}$ に変換して指数に統一
③ 指数のたし引き・かけ算で計算

🎉
