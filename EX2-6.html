📘 常用対数とは

底を 10 とする対数 $\log_{10} M$ を 常用対数 といいます。
日常でよく使う「10の何乗か」を表す対数で、桁数や小数の位の計算に役立ちます。

📌 常用対数の基本

$\log_{10} M$：10を底とする $M$ の対数

よく使う値：$\log_{10} 2 \approx 0.3010$、$\log_{10} 3 \approx 0.4771$

注意：$\log_{10} 10 = 1$、$\log_{10} 1 = 0$（EX2-2の性質①②）

📘 正の整数の桁数を求める

「$2^{30}$ は何桁の数か」のような問題を解けるようにしましょう。
まず、桁数と $10^n$ の関係を整理します。

2桁の整数
$10 \leqq M < 100$
$10^1 \leqq M < 10^2$
3桁の整数
$100 \leqq M < 1000$
$10^2 \leqq M < 10^3$
$n+1$桁の整数
$10^n \leqq M < 10^{n+1}$
⬆ これが一般公式
⭐ 桁数の公式

整数 $M$ が $n+1$ 桁 $\Leftrightarrow$ $10^n \leqq M < 10^{n+1}$

両辺に $\log_{10}$ をとると

$n \leqq \log_{10} M < n+1$

つまり $\log_{10} M$ の整数部分が $n$ ならば $M$ は $n+1$ 桁

注：「100 は $10^2$ で 3 桁」→ 指数 $2$ に $1$ を足すと桁数 $3$

📋 桁数を求める手順
① $\log_{10}(\text{求めたい数})$ を計算する
② 結果を $n \leqq (\text{値}) < n+1$ の形にはさむ
③ 桁数は $n+1$
📝 例題１

$\log_{10} 2 = 0.3010$ を用いて、$2^{30}$ の桁数を求めよ。

① 常用対数をとる

$\log_{10} 2^{30} = 30\log_{10} 2 = 30 \times 0.3010 = 9.03$

② はさんで桁数を決める

$9 \leqq 9.03 < 10$ なので

$9 \leqq \log_{10} 2^{30} < 10$

$10^9 \leqq 2^{30} < 10^{10}$

$\therefore\ 2^{30}$ は 10桁 の数

📝 例題２（やや複雑）

$\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$ として、$18^{50}$ の桁数を求めよ。　〈群馬大〉

① $18 = 2 \times 3^2$ に分解して常用対数をとる

$\log_{10} 18^{50} = 50\log_{10} 18$

$= 50\log_{10}(2 \times 3^2)$

$= 50(\log_{10} 2 + 2\log_{10} 3)$

$= 50(0.3010 + 2 \times 0.4771)$

$= 50 \times 1.2552 = 62.76$

② はさんで桁数を決める

$62 \leqq 62.76 < 63$ なので

$10^{62} \leqq 18^{50} < 10^{63}$

$\therefore\ 18^{50}$ は 63桁 の数

Q1. $\log_{10} 3 = 0.4771$ のとき、$\log_{10} 3^{20}$ の値はいくつですか？
Q2. $\log_{10} 3^{20} = 8.542$ のとき、$3^{20}$ は何桁の数ですか？
✏️ 練習問題① 桁数を求める
問1　次の数の桁数を求めなさい。ただし $\log_{10} 2 = 0.301$、$\log_{10} 3 = 0.4771$ とする。

(1) $2^{30}$

(2) $3^{20}$　〈類題〉

(3) $5^{30}$

(1) $\log_{10} 2^{30} = 30 \times 0.301 = 9.03$
$9 \leqq 9.03 < 10$ → $10^9 \leqq 2^{30} < 10^{10}$　→　10桁

(2) $\log_{10} 3^{20} = 20 \times 0.4771 = 8.542$
$8 \leqq 8.542 < 9$ → $10^8 \leqq 3^{20} < 10^9$　→　9桁

(3) $\log_{10} 5 = \log_{10} \dfrac{10}{2} = 1 - \log_{10} 2 = 1 - 0.301 = 0.699$
$\log_{10} 5^{30} = 30 \times 0.699 = 20.97$
$20 \leqq 20.97 < 21$ → $10^{20} \leqq 5^{30} < 10^{21}$　→　21桁
問2　$\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$ として $18^{50}$ の桁数を求めよ。　〈群馬大〉
$\log_{10} 18^{50} = 50\log_{10}(2 \times 3^2)$
$= 50(\log_{10} 2 + 2\log_{10} 3)$
$= 50(0.3010 + 0.9542) = 50 \times 1.2552 = 62.76$
$62 \leqq 62.76 < 63$ → 63桁

📘 小数の位を求める

今度は $\left(\dfrac{1}{3}\right)^{100}$ のような小さな数が「小数第何位に最初の0でない数字が現れるか」を求めます。

小数第1位に最初の数字

$0.1 \leqq A < 1$

$10^{-1} \leqq A < 10^0$

小数第2位に最初の数字

$0.01 \leqq A < 0.1$

$10^{-2} \leqq A < 10^{-1}$

小数第$n$位に最初の数字

$10^{-n} \leqq A < 10^{-n+1}$

⬆ 一般公式

⭐ 小数の位の公式

$10^{-n} \leqq A < 10^{-n+1}$ のとき

$\Leftrightarrow$ $-n \leqq \log_{10} A < -n+1$

→ $A$ は小数第 $n$ 位に初めて0でない数字が現れる

📝 例題３

$\left(\dfrac{1}{3}\right)^{100}$ を小数で表すと、小数第何位に初めて0でない数字が現れるか。
ただし $\log_{10} 3 = 0.4771$ とする。

① 常用対数をとる

$\log_{10}\!\left(\frac{1}{3}\right)^{100} = 100\log_{10} \frac{1}{3}$

$= 100(\log_{10} 1 - \log_{10} 3) = 100(0 - 0.4771)$

$= -47.71$

② はさんで位を決める

$-48 \leqq -47.71 < -47$ なので

$10^{-48} \leqq \left(\dfrac{1}{3}\right)^{100} < 10^{-47}$

$\therefore$ 小数第 48位 に初めて0でない数字が現れる

🔖 桁数と小数の位の比較
桁数：$\log_{10} M$ の整数部分を $n$ とすると → $n+1$ 桁
小数の位：$\log_{10} A = -47.71$ → $-48 \leqq -47.71 < -47$ → 小数第 48 位
（$-47.71$ の「整数部分」は切り捨てで $-48$、つまり $|-48|=48$ 位）
Q1. $\log_{10} 2 = 0.301$ のとき、$\log_{10}\!\left(\dfrac{1}{2}\right)^{10}$ の値はいくつですか？
Q2. $\log_{10}\!\left(\dfrac{1}{2}\right)^{10} = -3.01$ のとき、$\left(\dfrac{1}{2}\right)^{10}$ は小数第何位に初めて0でない数字が現れますか？
✏️ 練習問題② 小数の位・応用
問1　次の数は小数第何位に初めて0でない数字が現れるか求めなさい。

(1) $\left(\dfrac{1}{2}\right)^{10}$　　ただし $\log_{10} 2 = 0.3010$　〈西南学院大〉

(2) $\left(\dfrac{1}{5}\right)^{30}$　　ただし $\log_{10} 2 = 0.301$

(3) $\left(\dfrac{2}{3}\right)^{100}$　ただし $\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$　〈京都教育大〉

(1) $\log_{10}\!\left(\frac{1}{2}\right)^{10} = -10\log_{10} 2 = -10 \times 0.3010 = -3.010$
$-4 \leqq -3.010 < -3$ より　小数第 4位

(2) $\log_{10} 5 = 1 - 0.301 = 0.699$
$\log_{10}\!\left(\frac{1}{5}\right)^{30} = -30\log_{10} 5 = -30 \times 0.699 = -20.97$
$-21 \leqq -20.97 < -20$ より　小数第 21位

(3) $\log_{10}\!\left(\frac{2}{3}\right)^{100} = 100(\log_{10} 2 - \log_{10} 3)$
$= 100(0.3010 - 0.4771) = 100 \times (-0.1761) = -17.61$
$-18 \leqq -17.61 < -17$ より　小数第 18位
問2（入試）　$\log_{10} 2 = 0.3010$、$\log_{10} 3 = 0.4771$ として次の問いに答えよ。　〈京都教育大〉

(1) $\log_{10} 4$ の値を求めよ。

(2) $\log_{10} 5$ の値を求めよ。

(3) $\left(\dfrac{2}{3}\right)^{100}$ を小数で表したとき、小数第何位に初めて0でない数字が現れるか。

(1) $\log_{10} 4 = \log_{10} 2^2 = 2\log_{10} 2 = 2 \times 0.3010 = 0.6020$

(2) $\log_{10} 5 = \log_{10} \dfrac{10}{2} = \log_{10} 10 - \log_{10} 2 = 1 - 0.3010 = 0.6990$

(3) 問1(3)と同様：$-17.61$ → 小数第 18位
