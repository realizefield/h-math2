📘 対数関数のグラフと増加・減少

対数不等式を解くには、グラフが増加するか減少するかを理解することが必須です。
下の2つのグラフをよく見てください。

🔵 $a > 1$ のとき
右上がり（増加関数）
🔴 $0 < a < 1$ のとき
右下がり（減少関数）
🔵 $a > 1$（増加関数）

$x$ が大きくなると

$y$ も大きくなる

→ 不等号の向きはそのまま

🔴 $0 < a < 1$（減少関数）

$x$ が大きくなると

$y$ は小さくなる

→ 不等号の向きが逆転！

⭐ 対数不等式の核心ルール

$M > 0,\ N > 0$ のとき

$a > 1$ のとき： $\log_a M < \log_a N \Leftrightarrow M < N$（不等号そのまま）

$0 < a < 1$ のとき： $\log_a M < \log_a N \Leftrightarrow M > N$（不等号が逆転！）

⚠️ 必ず真数条件を確認！
EX2-4と同様に、真数 $> 0$ の条件を最初に設定し、
最後に求めた範囲と真数条件の共通部分をとります。
📘 基本型の解き方
📝 例題１

次の不等式を解きなさい。

(1) $\log_2(x+1) < 3$　　(2) $2\log_{\frac{1}{2}}(x-2) > \log_{\frac{1}{2}}(x+4)$

(1) 底 $a = 2 > 1$（増加関数）→ 不等号そのまま

真数条件$x + 1 > 0$ より $x > -1$ … ①

$3 = 3 \times \log_2 2 = 3\log_2 2 = \log_2 2^3 = \log_2 8$ と変形して $\log_2(x+1) < \log_2 8$

底 $2 > 1$ なので不等号そのまま：$x + 1 < 8$　→　$x < 7$ … ②

①と②の共通範囲より　$-1 < x < 7$

(2) 底 $a = \frac{1}{2} < 1$（減少関数）→ 不等号が逆転！

真数条件$x - 2 > 0$ かつ $x + 4 > 0$ より $x > 2$ … ①

$2\log_{\frac{1}{2}}(x-2) = \log_{\frac{1}{2}}(x-2)^2$ に変形

$\log_{\frac{1}{2}}(x-2)^2 > \log_{\frac{1}{2}}(x+4)$

底 $\frac{1}{2} < 1$ なので不等号が逆転：$(x-2)^2 < x + 4$

$x^2 - 5x < 0$　→　$x(x-5) < 0$　→　$0 < x < 5$ … ②

①と②の共通範囲より　$2 < x < 5$

🧪 確認しよう①
Q1. $\log_{\frac{1}{3}} M < \log_{\frac{1}{3}} N$ のとき、$M$ と $N$ の関係はどれですか？
Q2. $\log_2(x+1) < 3$ の解として正しいものはどれですか？
✏️ 練習問題① 基本型
問1　次の不等式を解きなさい。

(1) $\log_3(x-1) > 2$

(2) $\log_{\frac{1}{2}}(x-2) > -3$

(3) $\log_2(3x-7) < 2 - \log_2(x-1)$

(1) 真数条件：$x - 1 > 0$ より $x > 1$ … ①
底 $3 > 1$（増加）→ 不等号そのまま
$2 = 2 \times \log_3 3 = 2\log_3 3 = \log_3 3^2 = \log_3 9$
$\log_3(x-1) > \log_3 9$ → $x - 1 > 9$ → $x > 10$ … ②
①と②の共通範囲より　$x > 10$

(2) 真数条件：$x - 2 > 0$ より $x > 2$ … ①
底 $\frac{1}{2} < 1$（減少）→ 不等号逆転
$-3 = -3 \times \log_{\frac{1}{2}} \frac{1}{2} = -3\log_{\frac{1}{2}} \frac{1}{2} = \log_{\frac{1}{2}} \!\left(\frac{1}{2}\right)^{-3} = \log_{\frac{1}{2}} 8$
$\log_{\frac{1}{2}}(x-2) > \log_{\frac{1}{2}} 8$ → $x - 2 < 8$ → $x < 10$ … ②
①と②の共通範囲より　$2 < x < 10$

(3) 真数条件：$3x-7>0$ かつ $x-1>0$ より $x > \frac{7}{3}$ … ①
移項：$\log_2(3x-7) + \log_2(x-1) < 2$
$\log_2(3x-7)(x-1) < \log_2 4$
底 $2 > 1$（増加）→ $(3x-7)(x-1) < 4$
$3x^2 - 10x + 3 < 0$ → $(3x-1)(x-3) < 0$ → $\frac{1}{3} < x < 3$ … ②
①と②の共通範囲より　$\frac{7}{3} < x < 3$
🔶 確認テスト① 増加・減少・基本型
Q1. $\log_{\frac{1}{2}}(x-2) > -3$ を解くとき、不等号はどうなりますか？
Q2. $\log_{\frac{1}{2}}(x-2) > -3$ の解はどれですか？
📘 応用型：底の変換・2次不等式との組み合わせ

底が違う対数が混在するときは、底の変換公式で揃えてから解きます。

📝 例題２

$\log_2(x+2) \leqq 1 + \log_4(x+3)$ を解きなさい。　〈愛知工大〉

真数条件を確認する

真数条件$x + 2 > 0$ かつ $x + 3 > 0$ より $x > -2$ … ①

$\log_4$ を底 2 に変換して整理

$\log_4(x+3) = \dfrac{\log_2(x+3)}{\log_2 4} = \dfrac{\log_2(x+3)}{2}$

$\log_2(x+2) \leqq \log_2 2 + \dfrac{\log_2(x+3)}{2}$

両辺 $\times 2$：$2\log_2(x+2) \leqq 2 + \log_2(x+3)$

真数の比較（底 $2 > 1$、増加関数）

$\log_2(x+2)^2 \leqq \log_2 4(x+3)$

$(x+2)^2 \leqq 4(x+3)$

$x^2 - 8 \leqq 0$ → $-2\sqrt{2} \leqq x \leqq 2\sqrt{2}$ … ②

①と②の共通範囲より　$-2 < x \leqq 2\sqrt{2}$

📝 例題３

$2\log_{\frac{1}{2}}(x-3) < \log_{\frac{1}{2}}(2x-1)$ を解きなさい。　〈帝京大〉

真数条件

真数条件$x - 3 > 0$ かつ $2x - 1 > 0$ より $x > 3$ … ①

底 $\frac{1}{2} < 1$（減少関数）→ 真数比較で不等号逆転

$\log_{\frac{1}{2}}(x-3)^2 < \log_{\frac{1}{2}}(2x-1)$

減少関数なので逆転：$(x-3)^2 > 2x-1$

$x^2 - 8x + 10 > 0$ → $x < 4 - \sqrt{6}$ または $x > 4 + \sqrt{6}$ … ②

①と②の共通範囲より　$x > 4 + \sqrt{6}$
（$4 + \sqrt{6} \approx 6.4$、$x > 3$ との共通部分）

Q1. $2\log_2(x-3) < \log_2 4x$ で、底の変換後に比較する不等式はどれですか？
Q2. $2\log_2(x-3) < \log_2 4x$ の解はどれですか？（真数条件も考慮して）
✏️ 練習問題② 応用問題
問1　次の不等式を解きなさい。

(1) $2\log_2(x-3) < \log_2 4x$　〈神奈川大〉

(2) $\log_2(x+2) \leqq 1 + \log_4(x+3)$　〈愛知工大〉

(3) $2\log_{\frac{1}{2}}(x-2) > \log_{\frac{1}{2}}(2x-1)$　〈帝京大〉

(1) 真数条件：$x > 3$ … ①
底 $2>1$（増加）→ $(x-3)^2 < 4x$ → $x^2-10x+9 < 0$ → $(x-1)(x-9)<0$ → $1 < x < 9$ … ②
①と②の共通範囲より　$3 < x < 9$

(2) 真数条件：$x > -2$ … ①
$\log_4(x+3) = \frac{\log_2(x+3)}{2}$ と変換
両辺 $\times 2$：$2\log_2(x+2) \leqq 2 + \log_2(x+3)$
$\log_2(x+2)^2 \leqq \log_2 4(x+3)$
底 $2>1$（増加）→ $(x+2)^2 \leqq 4(x+3)$ → $x^2 - 8 \leqq 0$ → $-2\sqrt{2} \leqq x \leqq 2\sqrt{2}$ … ②
①と②の共通範囲より　$-2 < x \leqq 2\sqrt{2}$

(3) 真数条件：$x > 3$ … ①（$x-2>0$ かつ $2x-1>0$ の共通部分）
底 $\frac{1}{2}<1$（減少）→ $(x-2)^2 < 2x-1$ ← 不等号逆転
$x^2 - 6x + 5 < 0$ → $(x-1)(x-5) < 0$ → $1 < x < 5$ … ②
①と②の共通範囲より　$3 < x < 5$
🔶 確認テスト② 応用型
Q1. $\log_2(x+2) \leqq 1 + \log_4(x+3)$ で $\log_4(x+3)$ を底 2 で表すと？
Q2. $2\log_{\frac{1}{2}}(x-2) > \log_{\frac{1}{2}}(2x-1)$ の解はどれですか？（真数条件：$x > 3$）
